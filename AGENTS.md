# Инструкции агентам книги

Работаем по актуальным файлам `arkhanumforge/kniga`. Этот файл — точка входа, не второй свод канона. [GENERAL.md](GENERAL.md) определяет приоритеты, маршруты, подготовку, две вычитки и синхронизацию; правила и навыки [.cursor](.cursor/) применяются также в Codex и чате с GitHub, даже если автоматически не загружены.

1. Уточнить задачу, ветку/ref, выбранную версию, границу сцены и статус принятия; открыть GENERAL и соответствующий маршрут. Единственная рабочая ветка — main. Закреплять её актуальный commit; не создавать ветки без прямой просьбы автора.
2. Для плана, новой сцены, продолжения или существенной правки: обязательное ядро, четыре независимые карты знаний **целиком**, `Мир.md` по всем существенным механикам, полные блоки Лизы и важных героев, прошлый опыт по рукописи, актуальная физика и отношения, полный `Стиль.md`. Для диалога — `Химия и динамика диалогов.md`. Разные глубины маршрутов и переиспользование проверенного контекста описаны в GENERAL.
3. [rag/README.md](rag/README.md) — навигационное дополнение. Сверить свежесть по входным blob, открыть оригиналы; `selection_ready=false`: указатель, поисковый рейтинг и очередь кандидатов не подтверждают знание героя. Если поиск недоступен/неполон — прямое чтение; не угадывать.
4. Перед передачей художественного текста: логическая вычитка → отдельная художественная → повторная сверка изменившихся знаний, мотивов, физики и фактов. Первое лицо Лизы и фаза её открытости — по Стилю. Не вводить события и не синхронизировать общий канон из непринятого черновика.
5. Навыки: [brainstorm](.cursor/skills/brainstorm/SKILL.md), [plan-chapter](.cursor/skills/plan-chapter/SKILL.md), [ready-scene](.cursor/skills/ready-scene/SKILL.md), [write-scene](.cursor/skills/write-scene/SKILL.md), [close-scene](.cursor/skills/close-scene/SKILL.md). План глав 8+ — [шаблон](.cursor/rules/02-chapter-plan-structure.mdc). Коммит/пуш только по просьбе автора. Отвечать на русском, по-человечески; сообщать конкретный блокер, если существенный источник недоступен.

## Быстрые команды автора

- **1 подготовка** / `1-podgotovka` — [полная подготовка без прозы](.cursor/skills/1-podgotovka/SKILL.md).
- **2 написание** / `2-napisanie` — [написание после подтверждённой подготовки](.cursor/skills/2-napisanie/SKILL.md).
- **3 редактор** / `3-redaktor` — [подготовка и независимая литературная редактура](.cursor/skills/3-redaktor/SKILL.md).

В чате с GitHub короткая команда означает открыть указанный SKILL.md и выполнить его. В Cursor использовать соответствующий навык, если доступен. Для одноэтапной художественной задачи без команды сохраняется обычный маршрут GENERAL.
