## 6. Схема редакции на 4б/4в

По Архитектуре RAG §3–5, §9: четыре самостоятельных карты с метаданными holder, mainline, текущая точка и источник. Внутри — хронологические смысловые группы с наследуемыми полями. У записи стабильный ID K-LIZ/PAS/RAI/REA-…, subject, learned_at (глава/сцена/событие, unknown при пробеле), evidence (файл + конкретный эпизод), epistemic (наблюдение/рассказ/вывод/убеждение/неизвестность), confidence субъекта, отдельная author_assessment, transfer (кто → кому, содержание и момент; не передано/не установлено), supersedes/related. Для служебных авторских ответов отдельный блок author; для будущего status=planned/proposed, не accepted. Номер главы без момента не разрешает загрузить позднее раскрытие в начало главы. Не навязывать номера сцен там, где их ещё нет. У01–У11 — уже существующие ID улик, сохранить и связать с записями, не перенумеровывать.

Порядок выборки: до книги/ранние неизменные → до точки сцены → актуальная ступень каждого вывода + история → границы/неизвестное → новые передачи сцены отдельно. При переписывании вход до развилки. Для каждого субъекта отдельный срез. Авторский пакет может знать объективную механику, POV-пакет — только доступное на точке, включая ложные выводы. После скачка и ссоры не сливать карты. Дубли общей базы мужчин сохранять как отдельные записи или подтверждённые ссылки каждого, не считать всё известное одному автоматически известным другому. Не переносить протокол в новый источник до этапа 7, не включать эту карту аудита в выдачу писателю.

Предлагаемое деление редакции: 4б.1 — Лиза и читатель (сохранить У01–У11 и ранний опыт); 4б.2 — Паскаль и Райнор (общая база, индивидуальная передача, смена подозрений); 4в — сверка всех четырёх по резерву и первичным эпизодам, тест срезов, только затем закрытие. Это рабочее деление, не изменение общего плана.

## 7. Проверенные точки и редакционные риски

- Глава 6.md, строки 109–111, 409–415, 539, 597, 667: услышанный широкий срок, первое противопоставление типов, запах и вопрос Паскалю, повторная тяга на лечении. Гипотеза Лизы не равна объяснению Монклеров. Уточнять moment по сцене, не вводить точный срок её знания. Мир §6 (включая правила отпечатка, совпадения и эха) — авторский слой.
- Глава 7.md, 383, 489, 527–531, 639, 963–965: пробуждения, пальцы и закрытые глаза после убранного хлеба, интерпретация памяти, краткий доклад.
