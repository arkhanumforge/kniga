# Шпаргалка долгов

Рабочий учёт сюжетных закладок основной линии. Источники: [События по главам.md](<События по главам.md>), [Сейчас.md](Сейчас.md), планы глав, [Хронология.md](Хронология.md), [Персонажи.md](Персонажи.md), [План лора.md](<План лора.md>), [Арки (задумано).md](<Арки (задумано).md>) и [Мир.md](Мир.md). Точка написанного — засыпание в 8; гибель в рабочей 9 и допрос в 10 — planned. Q-001: объединение не утверждено. Служебное обозначение пленника не имя для POV.  
Если способ/срок закрытия не зафиксирован — пишем **не зафиксировано**. Автор дополняет.

**Как пользоваться перед сценой:** выбрать релевантные ближние долги и при уместности средние/дальние, не вводить обязательную квоту.  
**После «ок» сцены:** обновить реализацию долга здесь, события в событийном справочнике, знания в соответствующих картах; план не равен принятой сцене.

Две оси статуса: **реализация** (открыта / частично реализована / не начата / реализована по конкретному эпизоду) и **решение** (утверждённое, рабочее, открытое). Старые поля «Статус», «Задумано» и «Закрытие» ниже описывают детали; они не заменяют эти оси. Авторская истина не равна раскрытию для Лизы, читателя или мужчин; срезы проверять по независимым картам.

Обозначения прежнего учёта:
- **Открыт** — начат, не закрыт
- **Пишется** — закрытие/развитие уже в текущем плане главы
- **Задумано** — есть решение «что будет», но сцена ещё не на месте
- **Не зафиксировано** — правда/срок/форма закрытия ещё не утверждены автором
