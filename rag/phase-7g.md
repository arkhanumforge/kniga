Решения редакции: сокращены повторы маршрутных правил, а не профильная документация. Полный Стиль вместо набора отдельных правил, глубина маршрута зависит от задачи; для продолжения можно переиспользовать только доказанно неизменный прочитанный источник на той же точке. Роль дорогой модели не обещает автоматическое переключение. Устаревшая инструкция «отброшенные идеи удалять» заменена сохранением статусов и авторским контролем по плану ревизии. Правило обязательного отдельного хвоста преобразовано в обязательную функцию среза (отыгранное/эскалация/антиповтор/физика); при просьбе отдельный файл с реестром. Планы/содержательные файлы и рукопись не изменены. Указатели после этого коммита требуют перестроения по новым blob; не использовать прежний манифест до проверки. Полнота автоматического POV не доказана; четыре карты читать полностью.
