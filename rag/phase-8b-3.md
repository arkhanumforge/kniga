# 8б.3 — контроль знаний и раннего опыта

Четыре текущие карты прочитаны полностью: Лиза 205, читатель 180, Паскаль 157, Райнор 156 строк. Программно проверены 175 уникальных ID (162 K, 13 P), 430 вхождений, наличие обязательных полей у всех K, отсутствие неразрешимых ID. По картам: 48/6, 49/4, 33/2, 32/1. Сверка с первичным текстом — целевая, не новый полный перечит глав 1–8; прежний аудит сохранности служит основанием для остального.
