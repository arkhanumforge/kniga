# Поиск по книге (локально)

Без ключей и интернета.

**Обновить индекс** (дешёвая модель / после «закончили сцену» или конца главы):

```text
python rag/build_index.py
```

**Спросить:**

```text
python rag/query.py "что Лиза знает про кривого"
```

В индекс входят: Мир, Персонажи, События, Хронология, Шпаргалка долгов, Стиль, Сейчас, GENERAL, План лора, Книга, Глава*, План главы*, Хвост главы*.
