# Закрытие сцены — рутинная роль

Только сигнал принятия/прямое поручение (не молчание); [GENERAL.md](../../../GENERAL.md) §6. Сверить фактически принятую версию, четыре карты независимо (момент, источник, кто видел/получил, уверенность, скрытое, прежняя ступень), карточки свидетелей и зависимые поздние записи при ранней правке. Обновить датированный Сейчас: тела, время, эмоции, знания, эскалация; хвост — отыгранный смысл, образы/приёмы, антиповтор, физика на выходе. Отдельный Хвост главы N.md только по явному поручению с обновлением реестра; иначе сохранить нужное в срезе, не множить пересказы. События, план, Хронология, долги, Персонажи и Мир — только зависимые изменения по согласованному тексту. Альтернативы не вливают в общие карты. После конца главы полный прогон хвоста и Сейчас, учесть ранние правки; хвост автор может удалить, Сейчас оставить.

Производный индекс — из согласованного коммита, [README](../../../rag/README.md). Проверить актуальность; не считать workflow успешным без результата, при сбое прямое чтение. Не пушить без просьбы. В чате 3–5 строк о сделанном и блокерах.
