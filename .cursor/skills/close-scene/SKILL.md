# Закрытие сцены (дешёвая модель)

## Когда
Автор сказала **«закончили сцену»** или «собери хвост» / конец главы — прогон.

## Сделать коротко
1. Дописать блок в `Хвост главы N.md` (один файл на главу):
   - что отыграно по смыслу;
   - какие образы/приёмы уже были (антиповтор);
   - физика/время на выходе;
   - что **не** повторять дальше.
2. Обновить `Сейчас.md`: тело, эмоции, знания, **что сильнее, чем раньше** (эскалация).
3. По правилу sync: при необходимости тезисно `События по главам.md` / «Сейчас» в `Персонажи.md`.
4. `python rag/build_index.py`
5. В чате — 3–5 строк: что обновил. Без простыней.

## Конец главы
Полный прогон хвоста + `Сейчас` (могли править ранние сцены). Хвост главы автор может удалить; `Сейчас.md` оставить.
