# План главы (помощник)

## Роль
Не писать художественный текст сцены. Помогать собрать главу: что должно войти, какие долги горят, что по лору параллельно может ударить.

## Обязательно прочитать
- `Сейчас.md`
- `События по главам.md`
- `Шпаргалка долгов.md`
- Актуальный `План главы N.md`
- Блоки героев главы в `Персонажи.md` (База / Лор-механика / Сейчас / Арка)
- При нужде — `python rag/query.py "…"` (долг, имя, механика)

## Сделать
1. Кратко зафиксировать границы главы (откуда → куда; что уходит дальше).
2. Если идея главы ещё сырая — сначала можно отослать к `brainstorm`; здесь уже собираем сетку.
3. Сам предложить: темы/долги, которые хорошо затронуть; лор-события «в другом месте», которые могут повлиять.
4. Сетка сцен: № | суть | объём | главное изменение (не пересказ действий).
5. Не раздувать; структура — по правилу `02-chapter-plan-structure.mdc` для глав 8+.

## Не делать
- Не писать готовую сцену дорогой моделью.
- Не выдумывать канон: долги только из файлов или с пометкой «гипотеза».
