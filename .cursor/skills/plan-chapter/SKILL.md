# План главы

Выполнить [GENERAL.md](../../../GENERAL.md) §1–4: полная подготовка, четыре карты целиком с метаданными, предыдущая принятая точка и существенный опыт по оригиналам, Стиль, Мир, полные портреты, Арки, долги, планы и при необходимости отношения/Химия. Контролировать фактическое покрытие; при обрезании дочитать. Сырой замысел сначала brainstorm.

Для глав 8+ использовать [единый шаблон и проверку плана](../../rules/02-chapter-plan-structure.mdc). Начать с замысла главы, причинного входа/выхода, траекторий существенных героев и сетки сцен; затем разработать ход каждой сцены через мотивы, поступки, реакции, изменения знания/эмоций/отношений и последствия. Учитывать фазу Лиза—читатель, свидетелей, физику, лор и границы четырёх карт. Предлагать значимые долги, закладки и лор-параллели, не выдумывая их ради галочки.

Различать утверждённые авторские опоры, рабочие решения и открытые развилки; оставлять писателю свободу конкретной прозы. Задавать только содержательные вопросы, неразрешимые по оригиналам. Проверить причинность и стыки, не выдавать незавершённый план за готовый. Не писать прозу, не синхронизировать канон из планов, не менять другие планы или файлы без просьбы автора.
