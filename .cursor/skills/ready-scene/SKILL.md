# Сцена готова?

## Правило
Дорогой писатель (Sol) **не пишем**, пока план сцены не готов. Автор кидает мысли — агент предлагает — вместе держим концепцию.

## В плане сцены обязательно
- Исход: где тела, кто в кадре, время относительно прошлой сцены.
- **Головы:** чего хочет / боится / скрывает / знает каждый важный герой.
- Если есть диалог: **тон и дуга** (спокойно → давление → срыв…); **литературный смысл** (зачем диалог книге).
- Главное изменение сцены (новый результат, не список действий).
- Выход / сцепка со следующей.
- Атмосфера: из контекста (+ акцент автора, если сказала); стык с прошлой без резкого скачка жанра.
- Что **не жевать снова** из хвоста / прошлой сцены (если уже известно).

## Сверка
В конце спросить автора: **«сцена готова к написанию?»**  
Только после явного да — можно звать `write-scene` / Sol.
